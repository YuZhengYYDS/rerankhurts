# Oncology fact-review workbook

[Download the English review workbook](oncology_fact_review_english.xlsx). It contains 377 fact-level judgments and 1,241 source-evidence occurrences. Source support: 368 supported and 9 partially supported or conditional. Necessity: 375 appropriate and 2 not appropriate. The English version translates the original rationales and recommendations while preserving fact identifiers and source evidence.

An oncology expert completed and confirmed all 377 judgments. The [author disposition register](author_dispositions.json) records the decision to retain the existing 155-question rubric and numerical results. The workbook preserves each judgment and its qualifications.

The review evaluates source support and necessity against the study's bounded reference answers and frozen corpus. The [60-world review records](../../../strengthening/data/strengthening_v1/audit/reviews/) cover the separate data-semantic audit.
