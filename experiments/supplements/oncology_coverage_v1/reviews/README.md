# Oncology fact-review workbook

[Download the English review workbook](oncology_fact_review_english.xlsx). It contains 377 fact-level judgments and 1,241 source-evidence occurrences. The two judgment columns preserve the original outcomes: 368 supported and 9 partially supported or conditional; 375 appropriate and 2 not appropriate as necessary facts. The English version translates the original review rationales and recommendations; the source evidence and fact identifiers are preserved.

The authors state that an oncology expert personally made and confirmed all 377 judgments. The expert's name and institution are withheld for privacy. The workbook does not contain a human signature or independent attestation, so the authors' statement about reviewer identity is not independently verified by the file itself. An earlier version labeled the reviewer as ChatGPT and described AI-assisted review; the authors state that these reviewer labels were erroneous and requested their correction. The identity correction does not alter the judgments.

The review examines source support and necessity within the study's bounded reference-answer scope; it is not a clinical gold-standard dataset or a claim of current treatment guidance. Publishing the review does not change the frozen annotations, their historical provenance and adjudication metadata, or the reported results. The 60-world human audit is separate and is not documented here. See the [coverage package](../README.md) and [artifact guide](../../../../ARTIFACTS.md).
