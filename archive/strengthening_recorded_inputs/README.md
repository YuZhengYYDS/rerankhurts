# Recorded strengthening inputs and source

The 60-world human audit and Oncology expert annotation were completed before
the ICDE paper submission. The completed review records are linked below.

This directory preserves the exact specification, study plan and audit source
used by the recorded inference and scoring identities. The original input files
are retained byte-for-byte for reproducibility. This archive has no review-date
meaning; completion is documented in the review records.

- [Completed 60-world A/B human review](../../experiments/strengthening/data/strengthening_v1/audit/reviews/completion.json).
- [Completed Oncology expert review](../../experiments/supplements/oncology_coverage_v1/reviews/).

The maintained study plan and dataset specification link the completed review.
The integrity checker resolves recorded hashes to these unchanged input files
and checks that the current specification differs only in review metadata.
The maintained audit command writes only to new output directories.
